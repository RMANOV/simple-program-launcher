  Managed panes:       Claude (left)  Codex (right)  Shell  MAIN

  Launcher buttons "Claude Resume" and "Codex Resume" are request/focus
  commands.  They reuse the remembered session ID and never create a new
  Windows Terminal tab or kill an active writer.  A second click is a no-op
  while the same session is running; the existing pane is focused instead.

  Focus Claude from an existing CMD/PowerShell pane:
    cmd.exe /d /c wt.exe -w RManovQuad focus-tab -t 0 \; move-focus first

  Focus Codex from an existing CMD/PowerShell pane:
    cmd.exe /d /c wt.exe -w RManovQuad focus-tab -t 0 \; move-focus first \; move-focus right

  Inspect the durable per-agent state (read-only):
    pwsh.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File "D:\OneDrive - Крестън БулМар ООД\utilities\launcher\scripts\session_pane.ps1" -Mode Inspect -Agent claude
    pwsh.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File "D:\OneDrive - Крестън БулМар ООД\utilities\launcher\scripts\session_pane.ps1" -Mode Inspect -Agent codex

  "WT Quad (4)" is the only bootstrap command.  If the existing canonical
  window is found, it prints FOCUSED and restores that four-pane window without
  adding a tab.  The resume buttons likewise never repair a damaged layout by
  appending a tab.  If WT Quad reports CANONICAL-NOT-READY, no canonical
  workspace is proven; wait for Claude/Codex to be idle before a controlled
  rebuild.  Preserve exact session IDs and writer locks; never force-kill a
  live Claude/Codex process to make a pane appear.

  The `\;` delimiters above are intentional: in a CMD-launched WT command
  they separate `focus-tab`/`move-focus` actions.  Omitting the backslash can
  make WT treat the remaining split/focus commands as profile arguments.

  Modifier Logic:  Alt        = Navigate
                   Alt+Shift  = Split / Toggle
                   Alt+Ctrl   = Resize
                   Alt+Shift+Ctrl = Swap
                   Ctrl+Shift = Advanced actions
